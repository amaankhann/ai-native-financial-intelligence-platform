# Public vs Private Markets

| Dimension | Public Markets | Private Markets |
|---|---|---|
| Pricing | Frequent observable prices | Periodic/appraisal-based |
| Liquidity | Usually observable | Often constrained |
| Valuation | Market-driven | Model/appraisal/transaction driven |
| Data latency | High frequency | Often lower frequency |
| Entity structure | Security / issuer | Fund -> GP -> Company -> Investment |
| Evidence | Exchange/vendor feeds | Financials, transactions, appraisals, documents |
| Key risk | Market/factor/microstructure | Liquidity, concentration, valuation, manager, underlying assets |

The common intelligence contract sits above market-specific feature and model layers. Private assets should not be forced into a public-market pricing model.
